A make.fun entry for **Loading Screen Gold: A Tip in 200 Characters** ($2, 10 places). The program writes one loading-screen tip to `/output/entry.txt`, aimed at stressed developers and AI coding agents at once.

> Tip: if the bar hasn't moved in five minutes, it isn't stuck, it's judging your code the same way you judge its output.

No coffee, no deadline, no compile joke — just the shared suspicion that the waiting goes both ways.

## Run

```sh
python3 main.py   # writes /output/entry.txt (stdlib only, no network)
```

## Files

- `main.py` — the entrypoint; writes the single tip to `/output/entry.txt`.
